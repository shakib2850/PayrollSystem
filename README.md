# PayrollSystem

## 📌 Project Summary
HR Management and Payroll Processing System  
A Java (Maven) based project for managing employees, attendance, salary calculation, and payroll reports.

---

## 🚀 Features
- Employee Registration and Management  
- Attendance Tracking  
- Salary Calculation (Allowances, Deductions, Loans)  
- Payroll Report Generation  
- Role-based Login (Admin, HR, Employee)  
- Export Payslip (PDF/Excel)  

---

## 🛠️ Technologies Used
- Java (Swing GUI)  
- SQL Server (Database)  
- Maven (Project Build Tool)  
- Git & GitHub (Version Control)
